# What is a Browser?

A **browser** (or **web browser**) is a software application used to access, view, and interact with websites on the Internet. It helps users open web pages, search for information, watch videos, download files, and use online services.

**Example:** When you type `www.google.com` into a browser, it loads and displays Google's website.

## Types of Browsers (with Examples)

### 1. Graphical Browser

* Displays text, images, videos, and animations.
* Easy to use with a graphical interface (GUI).
* **Examples:**

  * Google Chrome
  * Mozilla Firefox
  * Microsoft Edge
  * Apple Safari
  * Opera

### 2. Text-Based Browser

* Displays only text (no images or videos).
* Used in terminals or command-line environments.
* **Examples:**

  * Lynx
  * Links
  * w3m

### 3. Mobile Browser

* Designed specifically for smartphones and tablets.
* Optimized for touch screens and mobile networks.
* **Examples:**

  * Google Chrome (Android)
  * Apple Safari (iPhone/iPad)
  * Samsung Internet

## Advantages of a Browser

* Access websites on the Internet.
* Search for information.
* Watch videos and listen to music.
* Download and upload files.
* Support bookmarks, tabs, and extensions.
* Provide security features like private browsing and safe browsing.

### Easy Definition (Exam Answer)

**Browser:** A browser is a software application that allows users to access, view, and interact with websites on the Internet.

**Examples:** Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, and Opera.
