# What is Software?

    Software is a collection of programs, instructions, and data that tells a computer how to perform specific tasks. It is the non-physical (intangible) part of a computer.

    Example:

    Microsoft Word – used to create documents.
    Google Chrome – used to browse the internet.
    Types of Software (with Examples)
## 1. System Software

    System software manages the computer hardware and provides a platform for application software to run.

    Examples:

    Operating System: Windows 11, Linux, macOS
    Device Driver: Printer Driver, Graphics Driver
    Utility Software: Antivirus, Disk Cleanup
    Language Translator: Compiler, Interpreter, Assembler
## 2. Application Software

    Application software is designed to help users perform specific tasks.

    Examples:

    General Purpose Software: Microsoft Word, Microsoft Excel, PowerPoint, Google Chrome
    Customized Software: Hospital Management System, School Management System, Banking System, Cosmetic Store Management System
## 3. Programming Software

    Programming software is used by programmers to develop, test, and debug programs.
    ```
    Examples:

    ```
    Compiler: GCC, Turbo C
    Interpreter: Python Interpreter
    Assembler: MASM
    IDE (Integrated Development Environment): Visual Studio, PyCharm, Eclipse
    
    ```
