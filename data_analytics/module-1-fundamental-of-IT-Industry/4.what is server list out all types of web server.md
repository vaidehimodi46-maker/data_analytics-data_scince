# What is a Web Server?

A **web server** is a software or computer system that stores, processes, and delivers web pages to users through a web browser using the **HTTP** or **HTTPS** protocol.

**Example:** When you open a website in your browser, the web server sends the requested web page to your browser.

## Types of Web Servers

### 1. Apache HTTP Server

* Free and open-source web server.
* One of the most widely used web servers.
* Supports Windows, Linux, and macOS.
* **Example:** Many educational and business websites use Apache.

### 2. Nginx

* High-performance and lightweight web server.
* Handles many users at the same time.
* Commonly used for high-traffic websites.
* **Example:** News websites and streaming platforms.

### 3. Microsoft Internet Information Services (IIS)

* Developed by Microsoft.
* Runs on Windows Server.
* Supports ASP.NET applications.
* **Example:** Company websites built with Microsoft technologies.

### 4. LiteSpeed Web Server

* Fast and secure web server.
* Compatible with Apache configuration.
* Improves website speed and performance.
* **Example:** Hosting providers use LiteSpeed for faster websites.

### 5. Lighttpd

* Lightweight and low-memory web server.
* Suitable for small servers and embedded systems.
* **Example:** Small websites and IoT devices.

### 6. Apache Tomcat

* Open-source web server for Java applications.
* Used to run Java Servlets and JSP.
* **Example:** Java-based web applications.

## Difference Between Browser and Web Server

| Browser                          | Web Server                             |
| -------------------------------- | -------------------------------------- |
| Used to view websites.           | Stores and delivers websites.          |
| Installed on the user's device.  | Installed on a server computer.        |
| Sends requests for web pages.    | Receives requests and sends web pages. |
| Examples: Chrome, Firefox, Edge. | Examples: Apache, Nginx, IIS.          |

## Advantages of a Web Server

* Stores website files.
* Delivers web pages to users.
* Handles multiple user requests.
* Supports HTTP and HTTPS.
* Improves website performance and security.

### Easy Definition (Exam Answer)

**Web Server:** A web server is software or a computer system that stores website files and delivers web pages to users through a web browser using HTTP or HTTPS.

**Examples:** Apache HTTP Server, Nginx, Microsoft IIS, LiteSpeed, Lighttpd, and Apache Tomcat.
