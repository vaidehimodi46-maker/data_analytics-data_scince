# What is a Protocol?

A **protocol** is a set of rules that defines how data is transmitted and received between computers or devices over a network or the Internet.

**Example:** When you open a website, your browser uses the **HTTP** or **HTTPS** protocol to communicate with the web server.

## Types of Network Protocols

### 1. HTTP (HyperText Transfer Protocol)

* Used to transfer web pages between a browser and a web server.
* Not encrypted.
* **Example:** `http://example.com`

### 2. HTTPS (HyperText Transfer Protocol Secure)

* Secure version of HTTP.
* Encrypts data using SSL/TLS.
* Used for banking, shopping, and login websites.
* **Example:** `https://www.google.com`

### 3. FTP (File Transfer Protocol)

* Used to upload and download files between computers.
* **Example:** Uploading website files to a web server.

### 4. SMTP (Simple Mail Transfer Protocol)

* Used to send emails.
* **Example:** Sending an email from Gmail or Outlook.

### 5. POP3 (Post Office Protocol Version 3)

* Used to receive emails by downloading them to a device.
* **Example:** Downloading emails to an email application.

### 6. IMAP (Internet Message Access Protocol)

* Used to access and manage emails directly from the mail server.
* Keeps emails synchronized across multiple devices.

### 7. TCP (Transmission Control Protocol)

* Provides reliable and error-free data transmission.
* Used for web browsing, email, and file transfers.

### 8. IP (Internet Protocol)

* Identifies devices and delivers data packets over the Internet.
* Every device connected to the Internet has an IP address.

### 9. UDP (User Datagram Protocol)

* Fast data transmission with low delay.
* Used for online gaming, live video streaming, and voice calls.

### 10. DNS (Domain Name System)

* Converts domain names into IP addresses.
* **Example:** Converts `www.google.com` into its IP address.

## Advantages of Protocols

* Enable communication between devices.
* Ensure accurate and reliable data transfer.
* Improve network security.
* Support email, web browsing, and file sharing.
* Standardize communication across different systems.
