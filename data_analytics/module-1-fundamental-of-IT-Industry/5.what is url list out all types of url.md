# What is a URL?

A **URL (Uniform Resource Locator)** is the **address of a resource on the Internet**. It tells a web browser where to find a webpage, image, video, or other online file.

**Example:** `https://www.google.com`

## Types of URL

### 1. Absolute URL

* Contains the complete web address, including the protocol (`http://` or `https://`) and domain name.
* Can be used from anywhere.

**Example:**

* `https://www.google.com`
* `https://www.wikipedia.org`

### 2. Relative URL

* Contains only the path to a file or page.
* Used within the same website.
* Does not include the protocol or domain name.

**Example:**

* `/about.html`
* `/images/logo.png`
* `products/mobile.html`

### 3. Static URL

* The URL remains the same and does not change.
* Usually points to a fixed webpage.

**Example:**

* `https://example.com/about.html`
* `https://example.com/contact.html`

### 4. Dynamic URL

* Generated automatically by the web server.
* Often contains parameters and symbols like `?` and `=`.

**Example:**

* `https://example.com/product?id=101`
* `https://example.com/search?name=laptop`

## Parts of a URL

Example URL:

`https://www.example.com/products/index.html`

| Part              | Description   |
| ----------------- | ------------- |
| `https`           | Protocol      |
| `www.example.com` | Domain Name   |
| `/products/`      | Folder/Path   |
| `index.html`      | Web Page/File |

## Advantages of URL

* Helps locate web pages on the Internet.
* Makes navigation easy.
* Allows sharing of websites.
* Identifies the exact location of online resources.
* Supports secure access using HTTPS.

### Easy Definition (Exam Answer)

**URL (Uniform Resource Locator):** A URL is the address of a webpage or resource on the Internet. It tells the browser where to find and open a website.

**Example:** `https://www.google.com`

**Types of URL:**

1. Absolute URL
2. Relative URL
3. Static URL
4. Dynamic URL
