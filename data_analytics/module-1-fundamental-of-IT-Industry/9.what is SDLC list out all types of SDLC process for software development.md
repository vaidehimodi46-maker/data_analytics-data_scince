# What is SDLC?

**SDLC (Software Development Life Cycle)** is a systematic process used to **plan, design, develop, test, deploy, and maintain** software. It helps developers create high-quality software in an organized and efficient way.

**Example:** Developing a **Cosmetic Store Management System** by following all development phases from planning to maintenance.

## SDLC Process (Phases)

### 1. Planning

* Identify project goals and requirements.
* Estimate cost, time, and resources.

### 2. Requirement Analysis

* Collect and analyze user requirements.
* Prepare the Software Requirement Specification (SRS).

### 3. System Design

* Design the software architecture, database, and user interface (UI).
* Create flowcharts and ER diagrams.

### 4. Development (Coding)

* Write the program code according to the design.
* Develop all software modules.

### 5. Testing

* Test the software to find and fix bugs.
* Ensure the software works correctly.

### 6. Deployment (Implementation)

* Install and release the software for users.
* Make it available in the real environment.

### 7. Maintenance

* Fix errors after deployment.
* Update and improve the software based on user feedback.

## Types of SDLC Models

### 1. Waterfall Model

* Development is completed step by step.
* Each phase must finish before the next begins.
* Best for projects with fixed requirements.

### 2. V-Model (Verification and Validation Model)

* Testing is planned alongside each development phase.
* Ensures high software quality.

### 3. Iterative Model

* Software is developed in small repeated cycles.
* Each iteration adds new features.

### 4. Incremental Model

* Software is built and delivered in small parts (increments).
* Users receive working software early.

### 5. Spiral Model

* Combines development with risk analysis.
* Suitable for large and complex projects.

### 6. Prototype Model

* A sample (prototype) is created first.
* User feedback is collected before final development.

### 7. Agile Model

* Software is developed in small, frequent releases.
* Focuses on teamwork, flexibility, and continuous customer feedback.

### 8. RAD (Rapid Application Development) Model

* Emphasizes fast development and quick delivery.
* Uses reusable components and user feedback.

## Advantages of SDLC

* Improves software quality.
* Reduces development cost and time.
* Makes project management easier.
* Helps identify and fix errors early.
* Ensures software meets user requirements.
* Simplifies maintenance and future updates.
