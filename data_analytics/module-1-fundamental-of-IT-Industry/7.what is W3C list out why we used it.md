# What is W3C?

**W3C (World Wide Web Consortium)** is an international organization that develops and maintains standards for the **World Wide Web (WWW)**. It was founded in **1994** by Tim Berners-Lee.

The main goal of W3C is to ensure that websites work correctly, consistently, and are accessible across different browsers and devices.

## Why is W3C Used?

W3C is used to create standards and guidelines that help web developers build websites that are compatible, secure, and accessible.

### Uses of W3C

1. **Creates Web Standards** – Develops standards for HTML, CSS, XML, SVG, and other web technologies.
2. **Browser Compatibility** – Ensures websites work properly in different web browsers.
3. **Accessibility** – Makes websites usable for people with disabilities.
4. **Improves Web Quality** – Encourages clean, valid, and well-structured web code.
5. **Supports New Technologies** – Develops standards for modern web applications.
6. **Promotes Security and Privacy** – Helps improve web security and protect user data.

## Advantages of W3C

* Makes websites compatible with different browsers.
* Improves website accessibility.
* Ensures high-quality web standards.
* Supports modern web technologies.
* Encourages secure and reliable websites.
* Helps developers write standardized code.

## Examples of W3C Standards

* **HTML** – Structure of web pages.
* **CSS** – Styling and design of web pages.
* **XML** – Data storage and exchange.
* **SVG** – Scalable vector graphics.
* **WCAG** – Web accessibility guidelines.
