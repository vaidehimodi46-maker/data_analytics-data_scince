## List 3 differences between MySQL and PostgreSQL in terms of features or use cases, and give one example of a popular app or company that uses each


    | Feature / Use Case | MySQL | PostgreSQL |
    |---|---|---|
    | Main Strength | Fast and simple for web applications | Powerful and suitable for complex applications |
    | Advanced Features | Supports standard SQL and is easy to use | Supports advanced data types, JSON, complex queries, and powerful indexing |
    | Best Use Case | Websites, e-commerce, and content management systems | Large, complex,    data-heavy applications and analytics |
    | Popular User | Facebook | Netflix |
